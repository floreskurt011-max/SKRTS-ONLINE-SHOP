SKRTS — VINTAGE-INSPIRED ONLINE SHOP
====================================

Files
-----
index.html  - Page structure and content
style.css   - Classy vintage styling, animations, and responsive layout
script.js   - Product catalog, search, filters, cart, totals, and checkout

How to run
----------
1. Extract SKRTS_online_shop.zip.
2. Open the SKRTS_online_shop folder.
3. Double-click index.html to open it in your browser.
4. No server or installation is required for this front-end demo.

Features
--------
- Product catalog with 12 sample products
- Product search
- Category filtering
- Add to cart, adjust quantities, and remove items
- Automatic subtotal, delivery fee, and total
- Checkout form with validation
- Payment method choices: GCash, GoTyme Bank, Maya, ShopeePay,
  GrabPay, other e-wallet, and Cash on Delivery
- Sample order confirmation and order number
- Smooth transitions and responsive styling

Demo delivery rule
------------------
- Free delivery for totals of PHP 1,500 or more
- PHP 80 delivery fee for totals below PHP 1,500
- Empty cart has no delivery fee

Important
---------
This is a front-end school project. Payment choices are selectable demo options;
no real payment is processed and no order is sent to a server. The cart resets
when the page is refreshed. Google Fonts are optional; fallback fonts are
included in the CSS.
